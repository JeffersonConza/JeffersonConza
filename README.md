## 💡 The idea behind a PINN

```python
# The PDE residual becomes part of the loss.
# Burgers 1D:  u_t + u·u_x − ν·u_xx = 0
residual = u_t + u * u_x - nu * u_xx
loss = data_loss + (residual ** 2).mean()
```
